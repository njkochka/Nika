# Нарезки интервью

Читать в начале любой сессии по нарезкам.

## Что это

Нарезки русских интервью в вертикальные шортсы: 60 секунд, если влезает без потери смешного, иначе до 80, сильная история до 90 ([[narezki-do-80-sekund]]). Каждый ролик -
законченная мини-история. Начали 2026-10-14, первый выпуск - Собчак и Самойлова.

**Стендап делать по `stendap-recept.md`**: слежение за лицом и все правки Орлова одним списком.

## Где что лежит

| Что | Где |
|---|---|
| Готовые ролики с музыкой | `готовые/<комик>/`, все подряд с номером («01 - название.mp4»), без подпапок. Нике копировать их на рабочий стол в одну папку, например «Айрапетов - без баннера» и «Айрапетов - с баннером» (ярлыка на рабочем столе больше нет) |
| Те же ролики без музыки (заготовки для пересборки музыки) | `<выпуск>/без музыки/` |
| Музыка из Epidemic Sound | `музыка/` |
| Рабочие файлы выпуска: исходник, расшифровка, конфиги роликов | `<выпуск>/`, например `orlov-1/` |
| Скрипты, модели лиц, Python-окружение | `.tools/` |
| Что уже выложено, по аккаунтам (сверять перед выкладкой, дописывать после каждой публикации; на разных аккаунтах ролики не повторяются) | `vylozheno.md` |

## Инструменты (`.tools/`)

- `fetch.sh ссылка выпуск audio|video` - скачать с YouTube. `audio` - только звук и сразу
  расшифровка (текст готов раньше видео), `video` - source.mp4. Не запускать расшифровку
  вместе со сборкой роликов.
- `compact.py выпуск/` - сжатая расшифровка `compact.txt` для чтения (уже нарезанное выкинуто).
- `sheet.py выпуск/ 60` - лист кадров с секундами: по нему выбрать образцы лиц для batch.json.
- `transcribe.py` - расшифровка (mlx-whisper), слова с таймкодами.
- `make_short.py` - сборка ролика по json-конфигу; `--plan` после конфига -
  только план без рендера. В конфиге `"out": "../готовые/Имя.mp4"`.
- `batch.py выпуск/batchN.json [1] [--plan]` - **главный способ делать пачку**: из короткого
  списка историй (название + диапазоны слов с пометкой h/g, кто говорит) сам пишет конфиги,
  рендерит по одному (Мак на 8 ГБ, параллель вешает систему), сам вырезает слова-паразиты и повторы, удаляет рабочие _tmp. `--only=N` - собрать один ролик, проверяет стыки, кладёт музыку. Баннер FloatUp `batch.py` ставит сам (копия в `готовые/<комик>/с баннером/`, `"banner": false` - без баннера), бот @floatupbanner_bot больше не нужен. `--plan` - только длины.
  Пример: `orlov-1/batch.json` (стендап, свои лица в `people`).
- Стендап и концерты: `"track": true` в cfg ролика - рамка плавно ведёт лицо, масштаб
  без зумов на склейках.
- `find.py выпуск/ --map | --min 12-15 | слова...` - кусок compact.txt вместо чтения целиком.
- `sents.py words.json a-b ...` - предложения с индексами слов, чтобы выбрать границы кусков.
- `build_all.sh` - старый способ: пачка роликов подряд + проверка стыков.
- `check_face.py ролик.mp4` - где лицо ушло от центра (для track-роликов).
- `check_cuts.py`, `check_words.py`, `check_edges.py`, `check_music.py` - проверки.
- `banner.py ролик.mp4 итог.mp4` - баннер FloatUp (`bannery/FloatUp.mp4`) один в один как бот
  @floatupbanner_bot (сверено с его роликами в ТикТоке polkovnikrostik 21.10.2026): до 60 сек
  включительно - в середине, 60-80 сек - на 0:20, длиннее - 0:20, 1:20, 2:20...; стоп-кадр,
  баннер ускорен в 1.4 раза, 928 px в ширину по центру, углы скруглены. Озвучка баннера с родной
  громкостью, как у бота. Ничего не менять против бота ([[obrazec-odin-v-odin]]).
  Баннер на уже готовые ролики пачки: `batch.py выпуск/batchN.json --music`.
- `add_music.py` - наложение музыки. `find_reactions.py` - кадры для вставок реакций.
- В ffmpeg нет libass/drawtext - субтитры рисуются через Pillow.
- Окружение пересоздать: `python3.11 -m venv .tools/venv`, потом
  `.tools/venv/bin/pip install -r .tools/requirements.txt`.

## Git

Видео, звук, картинки, рабочие `_tmp`-папки, Python-окружение и модели лиц
из `.tools/` в git не уходят (см. `.gitignore`). В git хранятся скрипты из
`.tools/`, конфиги роликов и расшифровки.

## Как искать истории экономно

Не читать words.json, transcript.txt и compact.txt целиком и не выписывать слова
по одному. Порядок:

1. `compact.py выпуск/` - обновить сжатую расшифровку (уже нарезанное выкинуто).
2. `find.py выпуск/ --map` - обзор: по строке на минуту (в 10 раз короче compact.txt).
3. `find.py выпуск/ --min 27-29` - прочитать только нужные минуты, или
   `find.py выпуск/ страшн спать` - найти строки по словам (`--all` - все слова сразу).
4. Края кусков уточнить через `sents.py words.json a-b`.
5. Записать batchN.json и запустить `batch.py`. Всё остальное делают скрипты.

## Экономия лимитов

Каждый шаг сессии заново отправляет всю переписку. Длинная сессия с большими
выводами съедает лимит в разы быстрее нескольких коротких.

- **Одна сессия = один ролик или одна правка.** Ролик готов - новая сессия.
  Новой сессии хватает этого файла и batchN.json, переписка не нужна.
- **Расшифровку целиком не читать** - только `find.py` и `sents.py` (см. выше).
- **Длинные выводы обрезать**: `| tail -20` у сборки и рендера, `| head -40`
  или `grep` у всего, что печатает много. Лог пачки смотреть через `tail`,
  json-конфиги не печатать целиком.
- Не перечитывать файлы, которые уже прочитаны в этой сессии.
